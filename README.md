# 여성곤의 논문 심사실

「민사신탁의 법리에 관한 연구」의 2026년 10월 24일 제출본을 검토하는 사이트입니다.

- 운영 주소: https://ysg.lawinus.org
- GitHub Pages가 화면을 제공하고 Supabase가 원고·원전·검토 메모·공통수정 이력을 저장합니다.
- 최신 자료 구분: `ysg-20261024` / 파일 저장소: `ysg-review-documents`
- 논문·참고문헌 나란히 읽기, 각주 이동, 본문 보기, 메모, 공동수정·이력·내보내기, 모바일 보기와 메뉴 접기를 지원합니다.
- 최신 논문은 215쪽·959문안(표행44개 포함)·각주189개입니다. 새 수정제안·번역은 아직 등록하지 않았습니다.
- 10월 23일 제출본과 기존 메모·수정 이력은 `/editions/20261023/`에서 계속 열 수 있습니다.
- 자료 연결과 인용면 확인은 구별합니다. 미확보 원전과 판본 불일치, 발췌본 범위는 각주·자료 상세정보에 표시합니다.

## 실행

Node.js 22.13 이상에서 `npm ci` 후 `public/config.example.json`을 `public/config.json`으로 복사하고 공개용 Supabase 연결값을 설정합니다. `npm run dev`로 미리 보고 `npm run build`로 정적 파일을 생성합니다. 관리자 키를 브라우저 설정에 넣지 않습니다.

`dist`를 GitHub Pages의 `gh-pages` 브랜치에 게시합니다. `public/CNAME`은 `ysg.lawinus.org`입니다. 원고·일반 원전 PDF는 Supabase에 보관하고, 검수된 공개 판례 텍스트와 경로·해시가 고정된 판례 PDF 2개만 Pages에 수록합니다. 개인 메모는 Git 저장소에 포함하지 않습니다.

## 데이터 보존

기존 데이터베이스의 함수를 재설치하지 않습니다. 새 제출본은 별도 자료 구분에 등록해 이전 원문·메모·이력을 보존하며, 이전 판본의 수정 이력을 새 원문에 덮어씌우지 않습니다. 본문·각주 갱신 시 웹 수정 이력을 먼저 전체 내보내기하고 원본과 대조합니다. `supabase/prepare-additive-seed.mjs`는 10월 23일 최초 등록용이므로 새 판본에 그대로 재실행하지 않습니다.

최신 설정의 `authDatasetId`와 `sourceDatasetId`는 `ysg-20261023`입니다. 전자는 기존 브라우저 방문자 연결을 유지하고 후자는 보존된 원전 파일을 다시 이용합니다. 최신 원고·목록·프로필과 공통 편집은 `datasetId`인 `ysg-20261024`를 사용합니다. 다른 자료 구분의 원고·메모·수정 이력과 저장소는 수정하지 않습니다.
